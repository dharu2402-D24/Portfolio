# Dharohar Mehta — Portfolio

A cinematic, high-performance interactive portfolio website showcasing visual design, UI/UX, 3D modelling, and frontend development work. Built with a focus on immersive aesthetics and smooth interactions.

---

## Tech Stack

- React
- Vite
- TypeScript
- Tailwind CSS
- Motion (Framer Motion)
- Three.js / React Three Fiber

---

## Getting Started

Clone the repository:

```bash
git clone https://github.com/yourusername/portfolio.git
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open:

```bash
http://localhost:5173
```

---

## Build

```bash
npm run build
```

---

## Project Structure

```bash
src/
├── app/
│   ├── data/       # Project data payload
│   ├── effects/    # 3D, physics, and animation wrappers
│   ├── pages/      # Full views (About, Projects)
│   ├── sections/   # Major page blocks (Hero, Footer)
│   └── ui/         # Reusable core components
├── assets/         # Optimized images
└── styles/         # Global CSS and Tailwind
```

---

## Features

- Interactive 3D elements (React Three Fiber)
- Physics-based typography interactions (JengaText)
- GPU-accelerated canvas background fields
- Smooth inertia scrolling via Lenis
- Dark minimal, highly atmospheric design
- Modular and scalable component structure
